This key is the only way back to your work. We store your work encrypted and we never see this key, so if you lose it your work cannot be recovered, by anyone. Conservez-la en lieu sûr et gardez-la privée : quiconque la détient peut ouvrir votre travail. Le travail enregistré est conservé 90 jours après votre dernière ouverture.

Private by designConfidentiel par conception

No email, no phone, no account. The text you work on is sent to an EU-hosted language model to generate Clau's replies: it is processed in the EU to answer you and is not saved in our database. If you choose to keep your work to continue later, it is encrypted in your browser under a key only you hold, so we cannot read that saved copy. We keep only minimal technical logs to prevent abuse. Your work is processed and stored in the EU.Ni e-mail, ni téléphone, ni compte. Le texte sur lequel vous travaillez est envoyé à un modèle de langage hébergé dans l'UE pour générer les réponses de Clau : il est traité dans l'UE pour vous répondre et n'est pas enregistré dans notre base de données. Si vous choisissez de garder votre travail pour le reprendre plus tard, il est chiffré dans votre navigateur sous une clé que vous seul détenez, si bien que nous ne pouvons pas lire cette copie enregistrée. Nous conservons uniquement des journaux techniques minimaux pour prévenir les abus. Votre travail est traité et stocké dans l'UE.
