Efficient Scalable Oversight via Rewinding

The authors introduce rewindable interactive proofs, a new model for scalable oversight where a weak verifier can save and restore an AI prover's state during interaction. They construct a protocol for oracle-aided computations with robust outputs where the honest prover runs in linear time and the verifier runs in near-linear time in input length, using no cryptography, and they report an implementation.

Cross-Controller Transfer via In-Context Behavior Adaptation

The authors study transferring robot data across embodiments and controllers by encoding behavioral interactions through examples of commanded actions and resulting motions, using a transformer context encoder for in-context adaptation. They report 33 percentage point improvement in average success over naive data pooling, with 50% success on unseen controller modes and effective adaptation on contact-rich tasks like USB insertion.

Continuous-Action World Models: Learning Cross-Embodiment Spatiotemporal Dynamics Priors

The authors propose Continuous-Action World Models (CoAWM), a framework learning cross-embodiment spatiotemporal dynamics priors through a shared latent function space over robot actions. They describe a two-stage approach where function pretraining aligns heterogeneous robot trajectories into a common representation, and a world-model backbone then predicts latent action functions conditioned on observations and language instructions.

Humanoid Dodgeball: Learning Fast Dynamic Obstacle Avoidance Motions for Humanoids

The authors present Humanoid Dodgeball, a reinforcement learning framework for agile dynamic obstacle avoidance in humanoid robots using threat-aware reward shaping and direction-specific adversarial motion priors. They report that the framework substantially improves evasive performance against incoming projectiles across diverse speeds and distances in both simulation and hardware experiments while preserving physically plausible whole-body motions.
